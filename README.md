# 🏹 Arrow Pop: Master Archer

An arcade bow-and-arrow balloon blaster web game featuring realistic physics, procedural audio, elemental bows, and combo streaks.

🎮 **Live Demo:** [https://deekshag96.github.io/balloon-blaster-app/](https://deekshag96.github.io/balloon-blaster-app/)

---

## 🎯 About The Game

**Arrow Pop** is a responsive 2D canvas archery game. Draw your bow, account for gravity and crosswinds, and pop rising balloons in target-based campaign levels or endless arcade blitz mode.

### Key Features
- **Realistic Archery Physics**: Elastic string pull, parabolic trajectory arc preview, and wind deflection.
- **Animated Archer Avatar**: Dynamically tracks aim angle and draws the bowstring.
- **Special Balloons**: 💣 Bomb (chain reaction), ❄️ Freeze (slow-mo), 🏹 Quiver (+ammo), ⭐ Star (bonus points).
- **The Armory**: Unlock 4 elemental bows (Oak, Phoenix Flame, Glacial Frost, Celestial Sovereign) with coins.
- **Fire Rush Mode**: Keep your combo streak alive to launch flaming piercing arrows.
- **Procedural Web Audio**: Real-time synthesized sound effects and carnival background melody.

## 🕹️ Controls

| Action | Control |
|---|---|
| **Aim & Draw** | Click/touch and drag backwards from the bow |
| **Shoot** | Release mouse / finger |
| **Sound / Pause** | Buttons in top HUD |

---

## 🛠️ Tech Stack

- **Frontend**: HTML5 Canvas, JavaScript (ES6+), Vanilla CSS (Glassmorphism)
- **Audio**: Web Audio API (100% procedural synthesis)
- **Bundler & Deploy**: Vite, GitHub Pages

## 🚀 Quick Start

```bash
# Clone and enter repo
git clone https://github.com/DeekshaG96/balloon-blaster-app.git
cd balloon-blaster-app

# Install & run
npm install
npm run dev
```
